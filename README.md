# H&M 推荐系统 - 10,000用户规模优化版本

## 📋 项目概述

这是一个针对 CPU 环境优化的 H&M 推荐系统，专门针对 10,000 名活跃用户进行设计。该系统实现了多路召回策略，并与纯热门 Baseline 进行对比。

## 🎯 核心特性

### 性能优化
- **适度降级采样**: 从 20,000 人调整为 10,000 名活跃用户
- **内存优化**: 使用双层 dict 存储 ItemCF 相似度矩阵，避免全量密集矩阵
- **计算提速**: 使用 pandas 向量化操作和 tqdm 进度条
- **内存监控**: 实时显示内存使用情况

### 召回策略
- **热门召回**: 基于最新一周商品热度
- **复购召回**: 基于用户历史购买记录
- **ItemCF召回**: 基于物品协同过滤
- **多路融合**: 综合多种召回策略

## 📊 实验流程

### 步骤 1: 生成 1 万人真实数据
- 读取原始 `transactions_train.csv`
- 统计用户购买次数
- 筛选前 10,000 名活跃用户
- 保存采样数据到 `data/` 目录

### 步骤 2: 跑纯热门 Baseline
- 仅使用热门商品召回策略
- 计算召回率、精确率、F1 等指标
- 作为对比基准

### 步骤 3: 跑多路召回对比
- 执行热门召回 + 复购召回 + ItemCF 召回
- 融合多路召回结果
- 计算各项指标并与 Baseline 对比

## 📈 优化亮点

### 内存优化
- 使用分块读取处理大文件
- 避免创建 $N \times N$ 全量相似度矩阵
- 只计算采样用户中真实交互过的商品相似度

### 计算优化
- 使用 pandas 向量化操作
- 添加 tqdm 进度条
- 实现高效的共现计算

### 对比实验
- 纯热门 Baseline 作为基准
- 多路召回策略对比
- 详细的性能指标分析

## 🎯 使用建议
